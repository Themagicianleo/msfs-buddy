# Airport data

`ourairports.json` is generated from the OurAirports data set
(https://ourairports.com/data/), which is released into the public domain.
It is not navigation data: no airways, procedures or AIRAC cycle.

When available, VOR/NDB beacons from openAIP (https://www.openaip.net) are
merged in. openAIP data is licensed CC BY-NC 4.0 (non-commercial use, with
attribution).

Last update: 2026-10-26. Rebuilt by `scripts/build-airport-data.ts`.
